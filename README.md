# APITrafficDocs

Turn the API calls a web app makes in your browser into OpenAPI documentation.

**Status:** early development. Not ready to use yet.

## v1 scope

- Chrome extension (DevTools panel) plus a standalone TypeScript engine
- REST APIs with JSON bodies
- Everything stays on your machine; secrets are redacted at capture time

See [docs/ROADMAP.md](docs/ROADMAP.md) for the roadmap.
